# Super Driver — سوبر درايفر

أداة أندرويد صغيرة وسريعة تقرأ **عرض الرحلة الظاهر على شاشة Uber Driver** وتحسب قيمة واحدة فقط:

> **السعر ÷ المسافة = السعر لكل كيلومتر**

ثم تعرض نتيجة واحدة من ثلاث: **مناسب** / **قريب** / **غير مناسب**.

مثال: `150 ج.م ÷ 8 كم = 18.75 ج.م/كم` → **مناسب**

---

## ما يفعله التطبيق

1. يقرأ نصوص شاشة Uber Driver أثناء ظهور عرض الرحلة.
2. يستخرج: **السعر** بالجنيه المصري، **المسافة** بالكيلومتر، و**اسم الخدمة** إن ظهر (UberX, Comfort, …).
3. يحسب **السعر ÷ المسافة** فقط.
4. يعرض النتيجة في بطاقة صغيرة عائمة فوق الشاشة، قابلة للسحب.

## ما لا يفعله التطبيق (مطلوبًا ومقصودًا)

- لا حساب للسعر بالساعة.
- لا حساب للمسافة المدفوعة أو نسبتها.
- لا تقييم للسائق أو للراكب.
- لا سجل للرحلات ولا إحصائيات.
- لا خرائط داخل التطبيق.
- لا مقارنة بين الرحلات.
- لا أي حساب إضافي غير السعر لكل كيلومتر.
- لا إنترنت، ولا Uber API، ولا أي خدمة خارجية: القراءة كلها من الشاشة وعلى الجهاز.

## العملة واللغة

- **العملة الوحيدة: الجنيه المصري** (`ج.م` / `جنيه` / `EGP` / `LE` / `E£`).
  لا يوجد أي دعم لـ USD أو `$` أو ARS أو Peso أو أي عملة أخرى، وشاشة بعملة أخرى تُتجاهل بدلًا من تخمين قيمتها.
- **لغتا التطبيق: العربية و English فقط** — وكل لغة أخرى مستبعدة من الملفات:
  - `resourceConfigurations` في `app/build.gradle.kts` تحذف أي ترجمة أخرى،
  - `res/xml/locales_config.xml` يبلّغ أندرويد 13+ باللغتين المدعومتين فقط،
  - شاشة الإعدادات تحتوي مُبدّل لغة (عربية/English).
- **لغة عرض أوبر المدعومة في القراءة: العربية والإنجليزية**، بالأرقام العربية-الهندية (`٢٫٥`) أو بالأرقام الغربية (`2.5`)، وبترتيب RTL أو LTR (`8.5 كم` أو `كم 8.5`).

## حدود التقييم

| النتيجة | الشرط (ج.م/كم) |
| --- | --- |
| مناسب | ≥ 10 |
| قريب | ≥ 6 وأقل من 10 |
| غير مناسب | أقل من 6 |

القيمتان الافتراضيّتان (10 و6) قابلتان للتغيير من شاشة الإعدادات.

## كيف يقرأ الشاشة

1. **شجرة الوصول (AccessibilityService)** — الطريقة الأساسية: تعطي نصوص الشاشة بدقة، وتعمل بالعربية بشكل كامل.
2. **تصوير الشاشة + OCR على الجهاز** — خطة بديلة تُستخدم فقط عندما لا تعطي الشجرة شيئًا مفيدًا (بعض الشاشات تُرسم على Canvas). تُلتقط صورة كل 700ms على الأكثر، وتُقصَّص المنطقة السفلية من الشاشة حيث تظهر بطاقة العرض، مع تحسين التباين قبل التحليل.

ملاحظة مهمة: مكتبة ML Kit للتعرّف على النص تدعم Latin/Chinese/Devanagari/Japanese/Korean فقط، أي **لا تدعم الحروف العربية**. لذلك تبقى شجرة الوصول هي الأساس، ويُستخدم تصوير الشاشة للقراءة الرقمية/الإنجليزية فقط.

## التشغيل والصلاحيات

1. افتح التطبيق وفعّل:
   - **خدمة الوصول** → "قارئ عروض أوبر".
   - **السماح بالعرض فوق التطبيقات**.
2. افتح **Uber Driver**. عند ظهور عرض رحلة تظهر البطاقة تلقائيًا، وتُخفي نفسها عند الخروج من أوبر.
3. البطاقة قابلة للسحب، ولها زر تحديث ⟳ وزر إخفاء ✕ (تعود تلقائيًا مع عرض جديد).

البطاقة غير قابلة لالتقاط التركيز (`FLAG_NOT_FOCUSABLE`) وصغيرة، أي أن أزرار القبول/الرفض في أوبر تبقى قابلة للضغط.

## المتطلبات

- Android 8.0 (API 26) فأعلى.
- تصوير الشاشة كخطة بديلة يحتاج Android 11 (API 30) فأعلى؛ بدونه يعمل التطبيق بالاعتماد على شجرة الوصول فقط.
- تطبيق Uber Driver المثبّت.

## البناء

```bash
# المرة الأولى فقط: توليد غلاف Gradle (ملف gradle-wrapper.jar غير مرفق في المستودع)
gradle wrapper --gradle-version 8.7

# بناء APK للتصحيح
./gradlew :app:assembleDebug

# تشغيل اختبارات المنطق (لا تحتاج جهازًا)
./gradlew :app:testDebugUnitTest
```

يتطلب JDK 17 و Android SDK 35.

## بنية المشروع

```
app/src/main/java/com/superdriver/app/
├── MainActivity.kt                     # الإعدادات: الصلاحيات، اللغة، الحدود، تجربة التحليل
├── core/                               # منطق خالص بلا أي اعتماد على أندرويد (قابل للاختبار)
│   ├── TextNormalizer.kt               # توحيد الأرقام/الحروف/الفواصل (عربي + إنجليزي)
│   ├── TripOffer.kt                    # نموذج العرض + المسافة الكلية + السعر لكل كم
│   ├── Verdict.kt                      # مناسب / قريب / غير مناسب
│   ├── TripOfferParser.kt              # استخراج السعر والمسافة واسم الخدمة
│   ├── UberServices.kt                 # مطابقة أسماء خدمات أوبر
│   └── Format.kt                       # تنسيق الأرقام للعرض
├── service/RideAccessibilityService.kt # قراءة الشاشة (شجرة الوصول ثم تصوير الشاشة)
├── overlay/OverlayController.kt        # البطاقة العائمة القابلة للسحب
├── ocr/ScreenOcr.kt                    # OCR على الجهاز (خطة بديلة فقط)
├── prefs/AppSettings.kt                # الحدود واللغة وخيارات القراءة
└── util/AppLocales.kt                  # العربية / English فقط
```

حزمة التطبيق: `com.superdriver.app`

## الاختبارات

`app/src/test` يحتوي اختبارات JUnit على المنطق الأساسي: شاشات عربية وإنجليزية، أرقام عربية-هندية، فواصل الآلاف، المسافات بالمتر، الوحدات قبل أو بعد الرقم، النصوص المقسّمة على أكثر من عنصر واجهة، وتجاهل USD/ARS/Peso والشاشات الناقصة.

```bash
./gradlew :app:testDebugUnitTest
```

## مرجع تقني

استُخدم مشروع [UberDriverCompanion](https://github.com/cnexans/panauber.vercel.app) كمرجع تقني فقط
(فكرة قراءة الشاشة عبر AccessibilityService + لقطة شاشة + OCR، وتقنيات تحسين الصورة قبل الـ OCR).
منطق القراءة نفسه أُعيد تصميمه بالكامل ليناسب أوبر مصر: الجنيه المصري فقط، العربية والإنجليزية،
حساب واحد فقط، وبدون سجل أو إحصائيات أو أي عملة أخرى.
