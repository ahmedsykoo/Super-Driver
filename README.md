# Super Driver — ملفات المشروع
- 01-docs: عرض الاستثمار + المواصفات v2 (تنبيه: بند Boost في v2 غلط، الصح في الـhandoff: Boost داخل السعر ولا يُجمع)
- 02-design: النموذج التفاعلي الأصلي (افتحه في المتصفح) + رابط الكانفاس الجديد تحت
- 03-handoff-and-tests: حزمة تسليم الوكيل + خطة الاختبار + ملخص الجلسة
- 04-android-project: مشروع Android (Kotlin) كتبه Claude Code. غير مبني وغير مجرّب على جهاز.

## الواجهة الجديدة (٢٠٢٦-١٠)
كانفاس تصميم تفاعلي جديد بالخمس شاشات (الرئيسية، الإعداد الأولي، الإعدادات، الاشتراك والدفع، سجل الرحلات)، نفس هوية Super Driver (كحلي/تركواز/عربي RTL) بترتيب وتفاصيل أحدث من `02-design/design-prototype.html` القديم:
https://claude.ai/artifact/Gw72bvpN49c6G23K6pTPJ2

شاشات التطبيق الحقيقي في `04-android-project` (Home / الإعداد الأولي / الإعدادات / سجل الطلبات — Kotlin، Views في الكود مش XML) اتحدّثت تواكب نفس اللغة البصرية دي (`ui/UiKit.kt`: ألوان وكروت وتوجلز وشريط تنقل سفلي). المنطق (Parser/Evaluator/Room/Accessibility) ما اتلمسش، التعديل بصري بس.

ملاحظة: شاشة "الاشتراك والدفع" موجودة في الكانفاس كتصميم مرجعي للمرحلة القادمة (T7/T8 في الـhandoff) — مش مبنية في كود Kotlin لسه.

## بناء APK
افتح 04-android-project في Android Studio ← Sync ← Build > Build APK(s) (debug). لسه غير مبني ولا مجرّب على جهاز حقيقي.
